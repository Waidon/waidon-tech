# Waidon Cloete — IT Support & Web Solutions

A mobile-first static portfolio built with semantic HTML, CSS and vanilla JavaScript. No framework, database or paid hosting required.

## Preview locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Important changes before launch
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email.
2. Replace `https://www.linkedin.com/` and `https://github.com/` with your actual profile URLs.
3. Review all experience, qualifications and certifications for accuracy. Add your verified dates and employer details only if you want them public.
4. Add real screenshots and links to completed projects. The current project visuals are illustrative CSS mockups, **not screenshots of completed projects**.
5. The Active Directory, networking, Linux and small-business demo cards are marked as planned or suggested. Do not change them to completed until you've actually finished them.
6. The website has no contact form/backend. Email links work after configuration; consider Netlify Forms or another form service if you need a form, plus appropriate privacy disclosures.
7. Replace this favicon or refine your visual identity if desired.

## Deploy to Netlify
- Create a free Netlify account.
- Choose **Add new project** → deploy manually by dragging this folder into Netlify Drop, or connect a GitHub repository for automated deployments.
- Verify your generated `*.netlify.app` URL.
- Under **Domain management**, add a custom domain you own and follow the DNS instructions provided by Netlify and your registrar.
- Wait for DNS/HTTPS provisioning and test the live site.
